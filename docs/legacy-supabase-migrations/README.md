# Migraciones anteriores

Estas migraciones pertenecen al modelo de casos original. Se conservan como referencia para el equipo, pero están fuera de `supabase/migrations` y no se aplicarán al proyecto Supabase nuevo.

El proyecto nuevo usa las migraciones activas de `supabase/migrations`. La migración de perfiles y roles original se mantiene allí para conservar la autenticación existente.
